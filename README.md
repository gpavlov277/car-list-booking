# Project Description

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 16.1.0

This project aims to create an Angular application for a vehicle booking website. The application will have various features to showcase and search for different vehicles. Users will be able to view vehicles, search for specific vehicle, create or edit vehicle and delete it.
1. Header Component: Develop a header component that will be displayed on all pages of the application. This component will contain HTML markup and CSS styles to create an appealing and consistent header.
2. Footer Component: Develop a footer component that will be displayed on all pages of the application.
3. Listing Vehicles: Create a vehicle model to represent vehicles and define their properties. Create car-list component where all users can see vehicles added to the database. Guest users also can see available vehicles.
4. Edit vehicle: Develop an edit page where Logged in users can edit current selected vehicle. Here usesr can only change vehicle's image or some fields.
5. Delete functuinality: Simple pop-up window where user can choose to delete current vehicle or not. Only logged in users can access that functionality.
6. Likes: Authrenticated users are able to like vehicles by clicking heart button at the home page of the application. When user likes a vehicle it is send to "Favourites".
7. Booking a vehicle: This functionality allows logged in users to book a vehicle from date to date with specific hour selected.
